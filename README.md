### Convertisseur de média de masse

## Transforme les médias d'origine depuis un dossier 'source' en média avec l'extension souhaité dans un dossier 'Output'.

Exemple : Vous avez des morceaux de vidéos de différentes origines .mkv, MP4, .avi et vous souhaitez les optimiser pour votre site Web.
=> Tous convertir en WebM.

Vous avez des images LOURDES de diverses origines et souhaitez que tout ça tienne peu de place dans votre mobile 
=>Tous convertir en WebP.
